The first release of FrankMoji Everywhere for Obsidian.

- Replaces standard emoji with [FrankMoji](https://frankmoji.com/) by Frank Rausch in reading view, Live Preview, and source mode.
- Also covers the rest of the app: the file list, tabs, search results, and popout windows.
- Your notes are never changed. Copy and paste, search, and screen readers still see the real emoji.
- Turn it on or off at any time from the command palette or the plugin's settings.
- The whole emoji set ships inside the plugin, so it works offline and makes no network requests.
- Works on desktop and mobile.

FrankMoji has no flags or family emoji, so those stay as your system draws them.
