Nothing changes in how the plugin works. This release is about trust in the download.

- The release files now come with a build attestation, so you can verify that `main.js`, `manifest.json`, and `styles.css` were built from this repository's source.
- The repository's license file is now the plain MIT text, so GitHub shows the license correctly. The credit for the emoji artwork moved to a `NOTICE` file and is unchanged.
